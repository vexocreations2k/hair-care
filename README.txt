RootCare package
- photo-check-app.html : photo-only hair check with score, medicine to ask a doctor about, and saved performance history
  (the photo analysis works when this page is opened from your claude.ai account; a store app needs its own image analysis service)
- manual-check-demo.html : demo where you type your own numbers (works offline in any browser)
- RootCare-app-design.pdf : 5 phone screens (Home, Progress, Medicine, Scan, Scan result)
- design-screens/ : source of each screen
- website/ : hair growth website (open index.html)
- performance-details.md : face-photo performance check details
Results are general information, not a diagnosis.
